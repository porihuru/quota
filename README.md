# アプリ概説
請求書作成
このアプリは、PDFファイルのプレビュー、ダウンロード、共有、メール送信をサポートしています。ユーザーはファイルの簡単な操作を行うことができます。

## 機能
- **PDFプレビュー**: ユーザーはアプリ内でPDFファイルをプレビューできます。
- **ダウンロード**: PDFファイルをローカルデバイスにダウンロードできます。
- **共有**: PDFファイルのリンクを他のユーザーと共有できます。
- **メール送信**: PDFファイルをメールで送信することができます。

## データ形式
アプリで使用されるデータは、`window.QUOTATION_DATA`というグローバル変数に格納されています。この変数には、アプリ全体で利用される引用データが含まれています。


## セットアップ手順
1. このリポジトリをクローンします。
2. 必要な依存関係をインストールします。
3. アプリをビルドして実行します。

## ファイル一覧
- `index.html`: アプリのメインHTMLファイル
- `app.js`: アプリの主要なJavaScript
- `style.css`: アプリのスタイルシート
- `assets/`: アプリに使用されるメディアファイル
